# Domain Docs

## Before exploring

Read the root `CONTEXT.md` for the domain vocabulary and the ADRs in
`docs/adr/` that relate to the work.

This is a single-context repository. If a referenced document is absent,
proceed without requiring it to be created upfront.

## Use the domain vocabulary

Use terms defined in `CONTEXT.md` in issues, proposals, hypotheses, and tests.
If a needed concept is missing, reconsider the terminology or note the gap for
the domain-modeling skill.

## Flag ADR conflicts

Explicitly identify any existing ADR that a proposal contradicts, and explain
why reopening the decision may be warranted.
